# Application assets

> **中文说明**：这份说明本目录里的**图标与字体资产及其许可**。

`app_icon.png` is the canonical Agentorium application icon. `app_icon.ico` is
the Windows-compatible icon generated from the same artwork.

The `fonts/` directory contains the WOFF2 files required by the native Qt
interface, including Material Symbols Outlined. The application loads these
files from this directory so a clean checkout does not depend on the original
Stitch design-source folder.

Unless a file states otherwise, original assets in this directory are included
under the repository's MIT License. Contributors must only submit artwork they
have the right to distribute.
